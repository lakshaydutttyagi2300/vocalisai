# Your own learning material

Put your own Markdown files here. They are kept when you update the app and included in backups.

- `my_content/knowledge/` - articles. Any `.md` file appears in the Knowledge Base (category "My articles").
  A title line like `# My SQL cheat sheet` at the top becomes the article title.
- `my_content/lessons/` - full lessons with exercises and quizzes, in the same format as the built-in lessons.
  Copy a built-in lesson from `content/python/...` as a template, give it a new unique `id`, and edit it.

The exact format is described in `docs/CONTENT_FORMAT.md`. If a file has a mistake, the app shows a
"content file problem" message explaining what is wrong - the rest of the app keeps working.
