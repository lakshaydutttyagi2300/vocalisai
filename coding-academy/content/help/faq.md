# Frequently asked questions

## Do I need Claude or any AI to use this app?
No. Everything essential works without any AI. The AI tutor is an optional extra.

## Do I need the internet?
Only to install the app. After that it works offline. See *Working offline, and what costs money*.

## Where is my progress stored?
In the `data` folder inside the app folder, in a file called `academy.db`. Settings shows the exact location.

## How do I move to a new computer?
Make a backup (Backup & Restore), copy the backup `.zip` to the new computer (or download it from Google Drive),
install the app there, start it, and use *Restore*.

## Should I learn Python or SQL first?
Either. If you have never programmed, start with Python Level 0. SQL can be started at any time and does not
need Python. Many people alternate.

## How long will it take?
Roughly 20-40 minutes per lesson including practice. Daily practice of 30 minutes gets you through the
beginner levels of both tracks in a few months.

## Why does the app say a lesson is "completed" but not "mastered"?
Completed means you met the lesson's criteria. Mastered also needs a high score across exercises and quizzes
*and* passing a spaced review on a later day - proof that you remember it.

## Can I break something by experimenting?
Not in the labs. Python code runs with safety limits inside a practice folder, and SQL runs on practice copies
that you can reset. Your progress database cannot be touched from the labs.

## Is the Python Lab a secure sandbox?
It is a safety net against accidents (endless loops, deleting files by mistake), not a defence against
deliberately malicious code. Only run code you understand. See the *How the lab keeps you safe* tab.

## Can I use my own code editor?
Yes. Write `.py` files in any text editor (VS Code is a popular free one) and run them from a terminal. The
*Files, folders and the terminal* lesson shows how.

## Why SQLite and not MySQL or PostgreSQL?
SQLite needs no installation and no server, so the app works out of the box. The SQL you learn transfers almost
unchanged. See *SQLite compared with other databases*.

## How do I update the app without losing progress?
See *Updating the app*. In short: make a backup, then replace the app files but keep the `data`, `backups` and
`my_content` folders.

## The app looks different on my phone.
The app runs on your computer. You can open it on the same computer's browser at any window size; narrow
windows hide the menu behind the **›** button in the top-left corner. (For safety, other devices cannot connect
to it.)
