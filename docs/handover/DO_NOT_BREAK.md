# DO NOT BREAK: working features to protect

These all work on the live site (checked through Phase 4 and the Phase 5 walk-through). Before changing anything near them:
1. run the named test;
2. run the full gate: `npx tsc --noEmit`, `npm test`, `npm run build`, then Playwright.
