# Handover package: index

Written 28 Sep 2026 so a new Claude Code account can continue this project with no lost context.

**Read in this order:**

1. `../../CLAUDE_NEW_ACCOUNT_START.md`: the briefing for the new Claude. Read it before changing any code.
2. `../../CURRENT_STATE.md`: a snapshot of the commit, what's done, bugs and next steps.
3. `../../NEXT_STEPS.md`: the prioritised roadmap.
4. `../../MIGRATION_CHECKLIST.md`: the owner's step-by-step checklist for moving accounts.

**Details:**

| File | Covers |
|---|---|
| `ARCHITECTURE.md` | stack, folders, main parts, API routes, models, feature flags, plans |
| `SERVICES_AND_SECRETS.md` | every external service and environment variable (placeholders only), and where to set each one |
| `CLAUDE_CODE_SETUP.md` | what does and doesn't transfer to a new Claude account; the MCP setup; the owner's standing instructions; the old memory notes |
| `GIT_AND_DEPLOYMENT.md` | branches, uncommitted work, what to commit or not, the release runbook |
| `FEATURE_STATUS.md` | status of every feature, with evidence |
| `KNOWN_ISSUES.md` | bugs, gaps, technical debt (prioritised table) |
| `QUESTION_BANK.md` | storage, sources, duplicates, fresh-first selection, categorisation |
| `LISTENING_SYSTEM.md` | listening storage, audio, raw-JSON protection, remaining gaps |
| `DECISION_LOG.md` | why things are the way they are |
| `SETUP_GUIDE.md` | fresh computer to a running app, tests and deploy |
| `DO_NOT_BREAK.md` | working features to protect, and how to test them |

`CHANGES.md` (repo root) holds the full phase-by-phase history with the finer technical detail.
